# Multilig Planner website

Static GitHub Pages website for Multilig Planner, a multiligament knee reconstruction planning application.

## Pages

- `index.html` — educational overview of multiligament knee surgery and the planning problem
- `demo.html` — interactive sample planning workspace

The site is developmental and educational. It is not validated for clinical care and is not intended to replace independent surgical judgment.

The custom-domain `CNAME` should be added after `multilig-planner.org` is registered and its DNS is ready to point to GitHub Pages.
